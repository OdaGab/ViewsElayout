# Views & Layouts - Exercícios Android

Este é um projeto de estudo desenvolvido no Android Studio para demonstrar e praticar o uso de diferentes Views e Layouts no desenvolvimento de aplicativos Android.

## Telas e Layouts Implementados

O projeto é composto por uma série de telas, cada uma focada em um componente de UI específico, com navegação sequencial entre elas.

1.  **LinearLayout (com Pesos):**
    *   Demonstra o uso de `LinearLayout` com `layout_weight` para criar layouts flexíveis que distribuem o espaço de forma proporcional.
    *   Arquivo: `activity_peso2.xml`

2.  **FrameLayout (com Animação):**
    *   Mostra como usar `FrameLayout` para sobrepor elementos (Views).
    *   Inclui uma `ListView`, uma `ProgressBar` e uma animação que simula um carregamento.
    *   Arquivo: `activity_frame_layout_pregressbar.xml`

3.  **TableLayout:**
    *   Exemplo de como organizar elementos em um formato de tabela, com linhas e colunas.
    *   Arquivo: `activity_exemplo_table_layout.xml`

4.  **RelativeLayout:**
    *   Demonstra o uso de `RelativeLayout` para posicionar elementos em relação uns aos outros. Usado para criar um formulário de login simples.
    *   Arquivo: `activity_relative_layout.xml`

5.  **ScrollView:**
    *   Exemplo de como permitir a rolagem vertical de um conteúdo que é maior que a tela.
    *   Arquivo: `activity_scroll_view.xml`

## Como Executar o Projeto

1.  Clone este repositório para a sua máquina local.
2.  Abra o projeto com o Android Studio.
3.  Aguarde o Gradle sincronizar as dependências do projeto.
4.  Execute a aplicação em um emulador ou em um dispositivo físico Android.
